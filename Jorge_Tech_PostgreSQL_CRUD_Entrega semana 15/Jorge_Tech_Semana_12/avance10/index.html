Soluciones tecnológicas a tu alcance

Jorge Tech es un proyecto web orientado a ofrecer servicios tecnológicos de manera clara, confiable y accesible. Esta página principal se mantiene como sección informativa, mientras que Flask permite organizar módulos internos para productos, clientes, proveedores y facturación.

El proyecto usa una estructura basada en plantillas. La plantilla base.html contiene menú, encabezado, pie de página, Bootstrap, CSS y JavaScript. Las páginas internas heredan esa estructura mediante Jinja2.
